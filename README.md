# Harshit Chemical Industry - E-Commerce Website

A modern, fast, and fully responsive static e-commerce web application built for **Harshit Chemical Industry** using HTML5, CSS3, and JavaScript. Designed with inspiration from top quick-commerce platforms like Blinkit, Instamart, and Zomato.

## Features
- **Auto Image Slider**: Smooth sliding hero banner that auto-rotates every 3 seconds.
- **Live Search & Filter System**: Instant product filtering by category, price range, and sorting.
- **Full E-Commerce Workflow**: Add to Cart, Quantity Management, Wishlist, Quick View, and Checkout Modal with COD.
- **Dark Mode Support**: Seamless toggle between Light and Dark themes with state retention in LocalStorage.
- **Extra UI Elements**: Floating WhatsApp, Call & Email buttons, Google Maps location, Back-to-Top button, and Toast notifications.
- **SEO & GitHub Pages Ready**: Complete meta tags, Open Graph tags, `robots.txt`, and `sitemap.xml`.
